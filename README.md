# Zachary Wadhams | Personal Website

Personal website of Zachary Wadhams, a Computer Science PhD student at Montana
State University researching cyber-physical system security and analysis.

Visit [zwadhams.github.io](https://zwadhams.github.io/).

## Sections

- **About:** Background, research interests, methods, and achievements.
- **Research:** Summaries of work on cyber-physical system security, software
  analysis, development workflows, and malware analysis.
- **Publications:** Papers and other research outputs, with publication details,
  citation counts, and links.
- **Experience & education:** Academic history and research positions.
- **Tool Wiki:** A linked directory for finding and comparing software analysis
  tools.
- **Contact:** Email and links to academic and professional profiles.

## Features

- Responsive layout for desktop and mobile.
- Weekly publication and citation updates from Google Scholar.
- Animated signal display with a pause control and reduced-motion support.
- Navigation that highlights the section currently being viewed.
