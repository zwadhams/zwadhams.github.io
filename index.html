Tool Wiki

After working with a variety of software analysis tools, I've found that one of the hardest parts is finding a tool that meets my needs. I built this wiki to make that search easier for myself and anyone facing the same challenge.

It brings together static and dynamic analysis tools, both free and paid, with details you can filter and compare to find a good fit. You'll also find guides to static analysis, dynamic analysis, and where the two overlap.

About me

Zachary WadhamsCyber-physical systems / Security & analysis

I'm a PhD student in Computer Science at Montana State University, where I work as a graduate research assistant in the Software Engineering and Cybersecurity Laboratory (SECL).

My research focuses on the security and analysis of cyber-physical systems (CPS), where software interacts with physical processes. I explore dynamic analysis in simulation and how static analysis findings can guide testing to uncover unsafe system behavior.

I earned an MS in Cybersecurity at Montana State University in 2024. My thesis examined SAST tool adoption, usability, and retention.

02 / RESEARCH

Research

01

Cyber-physical system security

I study static and dynamic testing methods for CPS to identify security weaknesses and unsafe system behavior. My work explores how these methods can complement each other to analyze software and its interactions with physical processes.

02

SAST adoption and usability

My literature review identifies barriers to using SAST tools, including false positives, poor output, setup time, manual effort, and workflow disruption.

03

CI/CD integration

I developed a process for collecting SAST findings and creating issues in a team's issue tracker, implemented with SonarQube and GitLab CI/CD.

04

SAST tool evaluation

I compare SAST findings across programming languages using Open Charge Point Protocol (OCPP) implementations. Related work examines software quality assessment for electric vehicle charging stations.

05

Malware sophistication

Our work defines malware sophistication and examines which software quality characteristics can be assessed from binaries using static analysis.
