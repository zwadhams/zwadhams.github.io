02 / RESEARCH

Questions I work on.

01

Static Application Security Testing

Investigating the adoption, usability, and effectiveness of SAST tools - identifying barriers developers face and designing solutions to improve retention and real-world impact.

02

DevSecOps & CI/CD Integration

Automating security analysis through CI/CD pipeline integration, making security a seamless part of the software development lifecycle rather than a post-hoc concern.

03

Malware Characterization

Developing frameworks to characterize and codify malware sophistication, supporting better threat modeling and defensive strategies for complex adversarial software.

04

Embedded & IoT Security

Analyzing security vulnerabilities in embedded systems like EV charging stations, examining how SAST tools perform across protocol implementations (e.g., OCPP).

05

Empirical Software Engineering

Applying empirical methods to measure and understand security tool performance, developer behavior, and the gap between tool capability and real-world adoption.

06

Software Quality & Technical Debt

Exploring the relationship between code quality, technical debt, and security posture - how software degradation creates exploitable vulnerabilities over time.
